== Debugging

The `nix repl` utility can be used to debug a styx site.

[source, shell]
.Starting nix repl from the styx repository
----
$ nix repl ./repl.nix
----

From a site directory, import `site.nix` with the same arguments your
`flake.nix` passes:

[source, shell]
.Starting nix repl in a site directory
----
$ nix repl
nix-repl> pkgs = import <nixpkgs> {}
nix-repl> styx = builtins.getFlake "github:styx-static/styx"
nix-repl> styxlib = styx.lib.${pkgs.system}
nix-repl> styxthemes = styx.legacyPackages.${pkgs.system}.styxthemes
nix-repl> site = import ./site.nix { inherit pkgs styxlib styxthemes; }
----


=== Inspecting site.nix attributes

[source]
.Inspecting the `conf` configuration set
----
nix-repl> site.conf
{ siteUrl = "https://example.com"; theme = { ... }; }
----

=== Using lib functions

[source]
.Using parseDate
----
nix-repl> with (site.lib.parseDate "2016-05-18T12:40:21"); "${date.lit}, ${time}"
"18 May 2016, 12:40:21"
----


=== Rendering a page source

[source]
.Rendering a page source
----
nix-repl> site = import "${styxthemes.generic-templates}/example/site.nix" {
             inherit pkgs styxlib styxthemes;
             sampleData = ./data/sample;
           }

nix-repl> with site; lib.generatePage (pages.about // { layout = templates.layout; }) # <1>
"<!DOCTYPE html>\n<html lang=\"en\">\n\n<head>\n  <meta charset=\"utf-8\">...."

nix-repl> with site; templates.layout (templates.page.full pages.about) # <2>
"<!DOCTYPE html>\n<html lang=\"en\">\n\n<head>\n  <meta charset=\"utf-8\">...."
----

<1> Rendering a page with the `generatePage` function.
<2> Rendering a page by running directly `layout (template page)`.


=== Building a site

It is possible to generate the site in the nix store from `nix repl`.

[source]
.Building a site
----
nix-repl> :b site.site
...
this derivation produced the following outputs:
  out -> /nix/store/...-styx-site
----

Or from the shell:

[source, shell]
----
$ nix build
$ ls ./result
----
