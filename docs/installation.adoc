== Installation

The only requirement for using Styx is the link:http://nixos.org/nix/[Nix package
manager] with flakes enabled. Refer to the
link:http://nixos.org/nix/manual/#chap-installation[Nix installation instructions]
to install Nix.

Styx is not installed as a global package anymore. You consume it as a flake
input in your site's `flake.nix`, or run one-off commands against the published
flake.

=== Try styx without creating a site

[source, shell]
----
$ nix run github:styx-static/styx#doc
----

Build the manual:

[source, shell]
----
$ nix build github:styx-static/styx#docs
----

Run the styx test suite (in a styx checkout or against the published flake):

[source, shell]
----
$ nix flake check github:styx-static/styx
----

=== Create a new site

[source, shell]
----
$ mkdir my-site && cd my-site
$ nix flake init -t github:styx-static/styx#default
$ nix build
----

The generated `readme.md` explains the next steps. See also <<Quick Start>>.

=== Development shell

When working on styx itself, enter the repository dev shell:

[source, shell]
----
$ nix develop
----

This provides `asciidoctor`, `pandoc`, and `statix`.
