= Styx library reference

== Data

=== loadFile

`loadFile { file, env ? {}, ... }` loads a single markdown, AsciiDoc, or `.nix` data file.

=== loadDir

`loadDir { dir, env ? {}, asAttrs ? false, filterDraftsFn ? ..., ... }` loads every supported file in a directory. Draft posts are omitted unless `conf.renderDrafts` is true.

=== markdownToHtml / asciidocToHtml

Convert markup strings to HTML using the built-in pandoc/asciidoctor commands.

== Pages

=== mkPageList

`mkPageList { data, template, pathPrefix ? "", pageFn ? ..., ... }` builds one page per data entry. Returns `{ list, pages, _type = "pages"; ... }`.

=== mkSplit

`mkSplit { basePath, itemsPerPage, data, ... }` splits a list into paginated archive pages. Each page gets `path`, `items`, `index`, and `pages`.

=== mkPages

Low-level helper used by `mkPageList`. Marks an attribute set with `_type = "pages"`.

== Site generation

=== mkSitePackage

Recommended site entry point. Loads themes, evaluates `data`/`pages`, and returns a derivation in `site`.

[source,nix]
----
styxlib.mkSitePackage {
  inherit styxlib;
  themes = [ styxthemes.generic-templates ];
  config = [ ./conf.nix extraConf ];
  extraEnv = { inherit pkgs; };
  body = loaded: rec {
    data = { };
    pages.index = {
      path = "/index.html";
      title = "Hello";
      content = "<p>Hi</p>";
      template = loaded.templates.page.full;
      layout = loaded.templates.layout;
    };
  };
}
----

`body` receives the loaded theme context and returns `{ data, pages, pagesDefault ? {}, mkSiteArgs ? {} }`.

=== mkSite

`mkSite { files ? [], pageList ? [], substitutions ? {}, meta ? {}, ... }` runs the shell script that writes HTML and copies static files.

=== pagesToList

`pagesToList { pages, default ? {} }` flattens the `pages` attribute set into a list, expanding `_type = "pages"` groups and applying optional defaults.

=== generatePage

`generatePage page` evaluates `page.layout (page.template page)`.

== Templates

=== normalTemplate

Wrap page content: `normalTemplate (page: "<h1>...</h1>")`.

=== mapTemplate

`mapTemplate f list` — `concatMapStringsSep "\n"` over rendered template fragments.

=== htmlAttr / htmlAttrs / escapeHTML

HTML attribute and escaping helpers for templates.

=== parseDate

Parse `YYYY-MM-DD` (optional time) strings into formatted fields for feeds and templates (`T`, `date.lit`, `b`, `B`, …).

=== processBlocks

Merge block-page content and collect `extraJS` / `extraCSS`.

== Themes

=== themes.load

`styxlib.themes.load { lib, themes ? [], config ? [], env ? {} }` merges theme modules with site config via `lib.evalModules`, loads templates, and returns `{ conf, files, templates, lib, env, themes }`.

Theme `conf.nix` files declare `options.*`; site config sets `config.*`.

== Utilities

=== find

`find criteria list` returns the first list element matching an attribute subset.

=== sortBy

`sortBy "date" "dsc"` sorts a list of attribute sets.

== Flake apps

Optional helpers for sites:

* `lib.apps.mkServe { site, host ? "127.0.0.1", port ? 8080 }`
* `lib.apps.mkServeWithLinkCheck { site, ... }`
* `lib.apps.mkGhPagesDeploy { site, remote ? "origin", branch ? "gh-pages" }`

== Module imports

Theme and site modules loaded from paths use `lib.modules.importApply` (available on `styxlib` through the merged nixpkgs lib).
