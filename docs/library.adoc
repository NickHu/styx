== Preface

The library contains functions used in `site.nix` and theme templates.

Styx APIs live under namespaced modules (`lib.data`, `lib.pages`, `lib.generation`,
`lib.template`, `lib.themes`, `lib.utils`, `lib.apps`). Nixpkgs helpers are also
available at the top level (`lib.optionalString`, `lib.recursiveUpdate`, and so on).

For a narrative introduction, see link:./index.html[Styx documentation].
