== Preface

The library contains functions used in `site.nix` and theme templates.

Styx APIs are available at the top level of `styxlib` (`lib.loadFile`, `lib.mkSitePackage`, …).
Nixpkgs helpers are merged in as well (`lib.optionalString`, `lib.recursiveUpdate`, …).
Themes use `lib.themes.load`; flake apps use `lib.apps.*`.

For a narrative introduction, see link:./index.html[Styx documentation].
