== Preface

The library contains various functions that can be used in `site.nix` and templates.

This appendix is a frozen snapshot of the former auto-generated reference. The
`documentedFunction` metadata and regeneration tooling were removed; update this
file by hand when library APIs change. Several sections still describe removed
APIs (taxonomies, multipages, `proplist`, and similar); prefer the narrative
docs under link:./index.html[Styx documentation] for current behavior.

Styx APIs live under namespaced modules (`lib.data`, `lib.pages`, `lib.generation`,
`lib.template`, `lib.themes`, `lib.utils`). Nixpkgs helpers are also available
at the top level (`lib.optionalString`, `lib.recursiveUpdate`, and so on).
