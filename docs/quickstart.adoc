== Quick Start

=== Create a new site

[source, bash]
----
$ mkdir my-site && cd my-site
$ nix flake init -t github:styx-static/styx#default # <1>
$ nix build # <2>
$ nix run .#serve # <3>
----

<1> Scaffold a new styx site in the current directory. This writes `flake.nix`,
    `site.nix`, `conf.nix`, and a few supporting files.
<2> Build the site. The output is symlinked at `./result`.
<3> Build again (with a local `siteUrl`) and serve the site at
    link:http://127.0.0.1:8080[http://127.0.0.1:8080]. Press kbd:[Ctrl+C] to stop.

A `readme.md` in the new directory walks through enabling a theme and adding a
first page. The styx manual is available with `nix run github:styx-static/styx#doc`.

It is recommended to read the <<site.nix,site.nix>> section to understand how a
site is structured.

=== Add sample content

To populate `data/sample/` with example pages and posts:

[source, bash]
----
$ nix flake init -t github:styx-static/styx#sample-data
----

Then wire the imported data into `site.nix` following the examples in the
link:./styx-themes.html[themes documentation].

=== Preview a bundled theme example

Each official theme includes an example site. To build one locally:

[source, bash]
----
$ nix build github:styx-static/styx#checks.x86_64-linux.generic-templates-site
$ nix shell nixpkgs#python3 -c python3 -m http.server 8080 --directory ./result
----

The generic-templates example will be accessible at link:http://127.0.0.1:8080[http://127.0.0.1:8080].
Check the posts: they explain several styx features.

Other official themes live in the link:https://github.com/styx-static/themes[styx-themes]
repository; this flake only bundles `generic-templates`.
