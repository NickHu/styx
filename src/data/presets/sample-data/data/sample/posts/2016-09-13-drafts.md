Draft posts are omitted from `loadDir` listings unless `config.renderDrafts` is true.

<!--more-->

Styx provides two approaches to manage draft content:

- Metadata
- Directories

## Using metadata

Set `draft = true` in front matter:

```markdown
{---
draft = true;
---}

## Lorem ipsum

Lorem ipsum dolor sit amet, consectetur adipiscing elit.
```

When loading posts with `lib.loadDir`, drafts are filtered automatically unless the site sets `config.renderDrafts = true` (for example in `extraConf` while previewing).

```nix
data.posts = lib.sortBy "date" "dsc" (lib.loadDir {
  dir = ./path/to/posts;
  env = loaded.env;
});
```

## Splitting directories

Keep drafts in a separate directory and merge when needed:

```nix
data.posts = let
  drafts = lib.loadDir { dir = ./path/to/drafts; env = loaded.env; };
  posts = lib.optionals (loaded.conf.renderDrafts or false) (lib.loadDir {
    dir = ./path/to/posts;
    env = loaded.env;
  });
in lib.sortBy "date" "dsc" (posts ++ drafts);
```

Build with drafts enabled via flake `extraConf`:

```nix
extraConf = { config.renderDrafts = true; };
```
