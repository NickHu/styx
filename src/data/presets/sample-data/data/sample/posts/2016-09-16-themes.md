This post introduces themes, a central concept in styx.

<!--more-->

Themes are more than just a way to customize a site looks.

A theme can provide:

- Template files
- Static files
- A configuration module (`conf.nix`)
- An example site
- An optional function library (`lib.nix`)

A theme can be extended by another, and multiple themes can be combined together.

## Basics

Themes are declared in `site.nix` inside `mkSitePackage`:

```nix
styxlib.mkSitePackage {
  themes = [
    styxthemes.generic-templates
    ./themes/my-theme
  ];
  ...
}
```

Themes at the beginning of the list have lower priority.

## Example sites

The bundled `generic-templates` theme includes an example site checked by `nix flake check` on the styx repository.

Preview it from a checkout:

```sh
$ nix build .#checks.x86_64-linux.generic-templates-site
```

## Configuration interface

Theme options are declared in `conf.nix` with `mkOption`. Site values are set in the site `conf.nix`:

```nix
{ lib, ... }:
{
  config.theme.site.title = "My site";
  config.theme.lib.bootstrap.enable = true;
}
```

Invalid values are caught at evaluation time by `lib.evalModules`.

## Documentation

Theme templates and options are documented in the styx manual:

```sh
$ nix build github:styx-static/styx#docs
```

See `styx-themes.html` for `generic-templates` template reference.
