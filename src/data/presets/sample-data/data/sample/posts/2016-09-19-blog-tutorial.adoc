Tutorial for creating a blog with the flake-native Styx workflow.

== Create a new site

Initialize a site from the Styx flake template:

[source, sh]
----
$ mkdir my-blog && cd my-blog
$ nix flake init -t github:styx-static/styx#default
----

This creates a `flake.nix`, `site.nix`, and `conf.nix`.

== Enable a theme

In `site.nix`, enable `generic-templates`:

[source, nix]
----
  themes = [
    styxthemes.generic-templates
  ];
----

== Add an index page

Inside the `body` function, declare pages using templates from the loaded theme:

[source, nix]
----
  body = loaded: rec {
    data = { };
    pages.index = {
      title    = "Home";
      path     = "/index.html";
      template = loaded.templates.page.full;
      layout   = loaded.templates.layout;
    };
  };
----

Preview the site:

[source, sh]
----
$ nix run .#serve
----

The site is served at http://127.0.0.1:8080. Press `Ctrl+C` to stop.

== Add sample data

Copy sample posts into your site:

[source, sh]
----
$ nix flake init -t github:styx-static/styx#sample-data
----

This adds content under `data/sample/`.

== Load data and posts

Extend the `body` function:

[source, nix]
----
  body = loaded: rec {
    data = {
      about = lib.loadFile { file = ./data/sample/pages/about.md; env = loaded.env; };
      menu  = [ pages.about ];
      posts = lib.sortBy "date" "dsc" (lib.loadDir {
        dir = ./data/sample/posts;
        env = loaded.env;
      });
    };

    pages = {
      index = {
        title    = "Home";
        path     = "/index.html";
        template = loaded.templates.page.full;
        layout   = loaded.templates.layout;
      };

      about = data.about // {
        path     = "/about.html";
        template = loaded.templates.page.full;
        layout   = loaded.templates.layout;
      };

      posts = lib.mkPageList {
        data       = data.posts;
        pathPrefix = "/posts/";
        template   = loaded.templates.post.full;
        layout     = loaded.templates.layout;
      };
    };
  };
----

`loadDir` reads every supported file in a directory; `sortBy` orders the result.

== Split the index into archive pages

Use `mkSplit` to paginate the post list on the index:

[source, nix]
----
    pages = rec {
      index = lib.mkSplit {
        title        = "Home";
        basePath     = "/index";
        itemsPerPage = 5;
        template     = loaded.templates.page.split;
        data         = pages.posts.list;
        layout       = loaded.templates.layout;
      };

      ...
    };
----

== Add an Atom feed

[source, nix]
----
      feed = {
        path     = "/feed.xml";
        template = loaded.templates.feed.atom;
        layout   = lib.id;
        items    = lib.take 10 pages.posts.list;
      };
----

== Configure the theme

Edit `conf.nix` with NixOS-style options:

[source, nix]
----
{ lib, ... }:
{
  config.siteUrl = "https://example.com";
  config.theme.site.title = "My Styx Blog";
  config.theme.lib.bootstrap.enable = true;
  config.theme.lib.highlightjs.enable = true;
}
----

== Default layout for all pages

Return a `pagesDefault` attrset from `body`:

[source, nix]
----
  body = loaded: rec {
    ...
    pagesDefault = { layout = loaded.templates.layout; };
  };
----

Then drop repeated `layout = loaded.templates.layout` from individual pages.

== Check links

[source, sh]
----
$ nix run .#linkcheck
----

== Build for production

[source, sh]
----
$ nix build
$ nix flake check
----

The built site is at `./result`.
